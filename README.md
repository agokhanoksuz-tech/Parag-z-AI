# Paragöz AI

AI destekli fiyat karşılaştırma ve alışveriş asistanı.

## V1 Hedefi

- Kullanıcı ürün adı girer
- Sistem gerçek veri kaynağından fiyatları toplar
- Fiyatlar toplam maliyete göre sıralanır
- AI, en mantıklı seçeneği yorumlar

## Mimari

- Console: Kullanıcı ile iletişim
- Core: Temel modeller
- Application: İş kuralları
- Infrastructure: Dış servisler, veri sağlayıcılar

## Veri Stratejisi

Öncelik API tabanlı veri kaynaklarıdır.
Site kazıma yalnızca kullanım şartlarına uygun olduğunda düşünülür.

## Yol Haritası

1. Proje altyapısı
2. Gerçek fiyat veri kaynağı
3. AI analizi
4. Web arayüz
5. Fiyat geçmişi ve alarm sistemi
